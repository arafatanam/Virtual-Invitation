# Hamza & Tahia, concept 2: image prompts for Gemini

Generate the images below, then put them in **`desi/h&t/concept-2/images/`** using the exact file names given. Once they're there, I'll fit them into the story, its animations and its text.

## Before you start

1. **Generate the character reference (image 00) first.** Attach it to every later prompt with the line *"Use the attached image as the character reference: same faces, same outfits, same art style."* This keeps Hamza and Tahia looking like the same people in every scene.
2. **Use portrait format 9:16 at the highest resolution Gemini offers.** The scenes fill a phone screen, and some are zoomed into.
3. **Ask for no text anywhere.** Image generators often add fake lettering, so every prompt already includes the no-text line. If text still appears, reply: *"Remove all text, letters and signatures; change nothing else."*
4. **Leave the empty areas empty.** Many prompts ask for clear space, because the invitation's text sits there. Regenerate if that space gets filled.
5. **Fix one detail at a time.** If one part is wrong, ask Gemini to change only that part ("Keep everything identical, only…"). Don't regenerate from scratch.
6. **Make the couple look like themselves.** To make the characters resemble Hamza and Tahia, add a description or attach a photo when you create image 00.
7. **Save as JPG.** For the two optional cut-outs (07b, 05b), save as PNG on a plain white background.
