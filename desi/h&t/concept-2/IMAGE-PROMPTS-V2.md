## How to get consistent frames (please read)

1. **Make image 00 (the character sheet) first.** Attach it to every later prompt and add: *"Use the attached character sheet: same faces, hair, outfits and art style."*
2. **Build each scene as a chain of edits, not fresh images.** Make the first frame of a scene, then attach it and ask Gemini to change only what the prompt says. Start every edit with **"Keep this exact image: the same composition, camera angle, framing, buildings, objects and people in the same positions. Change only the following:"** Frames that line up exactly are what make the crossfades look like motion rather than jumps.
3. **If something drifts** (a building moves, a face changes, the framing zooms), reply: *"The layout drifted. Match the attached original exactly and redo only the requested change."*
4. **Every image is portrait 9:16 at the highest resolution available**, except the garland strip (16:5).
5. **No text anywhere.** If lettering appears, reply: *"Remove all text, letters and signatures; change nothing else."*
6. **Leave empty areas empty.** Some frames need quiet space because the invitation's text sits there.
7. **Cut-outs (the boat and the walking couple) go on pure flat white**, with no shadow and no floor.
